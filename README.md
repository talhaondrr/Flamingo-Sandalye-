# Flamingo Sandalye — V6 Hibrit Katalog Sitesi

Bu sürümde ana sayfa, markayı ve ürün akışını tek bir modern sayfada toplar; tüm modeller ve ürün detayları ayrı sayfalarda kalır.

## Ana sayfa akışı

- Güçlendirilmiş hero alanı ve teklif çağrıları
- 4 öne çıkan model
- Ahşap rengi ve kumaş seçimi tanıtımı
- Hakkımızda özeti
- Cafe / restoran / otel ve toplu sipariş bölümü
- Talep konusu seçilebilen WhatsApp iletişim formu

## Ürün sistemi

- `urunler.html` — tüm modeller
- `urun-detay.html?model=...` — model bazlı dinamik ürün detayı
- Ürün galerileri
- Ahşap rengi + kumaş seçimi
- Adet seçimi
- Seçimleri `0501 095 19 13` numarasına WhatsApp mesajı olarak gönderme

> Ahşap ve kumaş seçenekleri şimdilik temsilidir. Gerçek kartela görselleri hazır olduğunda mevcut seçim alanına eklenebilir.

## Çalıştırma

Projeyi Visual Studio Code ile açıp `index.html` dosyasını Live Server ile çalıştırabilirsiniz. Statik HTML/CSS/JS yapısı nedeniyle doğrudan tarayıcıda da açılabilir.
