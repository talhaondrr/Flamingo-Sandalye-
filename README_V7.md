# Flamingo Sandalye V7 — Üretim Videosu Hero

Bu sürüm V6 Hibrit projesinden ayrı hazırlanmıştır.

## Yeni ana sayfa üst alanı
- Sandalye hero görseli kaldırıldı.
- Üretimden teslime marka hikâyesini anlatan video hero alanı eklendi.
- Video olmadığında `images/uretim-poster.webp` otomatik olarak kapak görseli şeklinde görünür.
- Video alanının hemen altında 8 aşamalı üretim süreci bulunur.
- Mobilde üretim aşamaları yatay kaydırılabilir.

## Gerçek üretim videosunu ekleme
`media` klasörüne videoyu şu isimle koyun:

`uretim-sureci.mp4`

HTML veya JavaScript değiştirmeniz gerekmez. Site videoyu otomatik olarak kullanacaktır.

Önerilen video: 10–20 saniye, 16:9 MP4/H.264, mümkünse 5–8 MB altında.
